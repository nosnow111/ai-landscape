Architecture

How it's built

1

Web research (Firecrawl → Tavily → Serper)

2 queries per section × 16 sections run concurrently before generation. Pulls current stats, pricing, and announcements to ground AI responses in live data — not training knowledge alone.

2

Claude Opus 4.8 generates structured JSON

Each section is a prompted JSON contract. Opus is primary for accuracy. All 16 sections run in parallel via ThreadPoolExecutor — full generation takes ~2–3 minutes instead of 30+.

3

GPT-4o cross-checks all ranked sections

Runs in parallel with Opus for 11 ranked sections. Agreement badges (✅ Consensus / 🟡 Minor diff / 🔴 Disagree) show on every card. Different training data makes disagreements meaningful.

4

Link validation + auto-fix

Every URL is fetched and checked for content relevance via Claude Haiku. Wrong-page links are auto-fixed using Tavily search. HTTP 403s (OpenAI etc.) are treated as valid.

5

Jinja2 builds static HTML → GitHub Pages

build.py renders index.html, news.html, and about.html from the JSON. No server needed — just static files served from docs/.

Quality control

How rankings are
verified

🤖 Dual-model cross-check

Claude Opus 4.8 and GPT-4o independently rank every section. Disagreements surface as visible badges — different training data makes them meaningful signals, not noise.

✅ Consensus 🟡 Minor diff 🔴 Disagree ⚪ GPT-4o excluded

🔗 Link validation

Every URL is fetched after generation. Claude Haiku checks page content relevance — not just that the page loads, but that it actually describes the right product. Auto-fixes wrong-page URLs using Tavily search.

📡 Live web grounding

Web search runs before every generation call, giving Opus and GPT-4o current data that post-dates their training cutoffs — new releases, pricing changes, updated rankings.

🏢 Aggregator weighting

Enterprise model traffic through AWS Bedrock, Azure OpenAI, Vertex AI, etc. is invisible in vendor API stats but represents massive real adoption. Prompts explicitly weight this signal.

10–15 smart cutoff rule: Always rank top 10. Extend to #11–15 only if adoption is within ~25% of #10 — no clear gap. Stop at the first significant drop-off. Never pad.

Resilience

Recovery options

🔁

Pipeline failed mid-run

Checkpoints are written after each stage. Just re-run python pipeline.py — it picks up from the last completed stage automatically. No wasted API calls.

🗃️

Stale or bad content

Content JSON files are committed to the repo. The site keeps serving the last good version even if a generation run fails. Force-regenerate a single section: delete its checkpoint file and re-run with --from=generate.

🔗

Broken URLs after generation

Run python validate_links.py --fix independently at any time. Produces a validation_report.json with every result. Use --dry-run to preview fixes without writing.

🔑

API key unavailable

Research degrades gracefully: Firecrawl → Tavily → Serper → none (Opus uses training data only). GPT-4o cross-check falls back to Claude Sonnet if OPENAI_API_KEY is missing. Site still builds from existing content.

🏗️

Template change only (no regeneration needed)

Run python pipeline.py --only=build — reads existing JSON, renders new HTML in seconds, no API calls.
